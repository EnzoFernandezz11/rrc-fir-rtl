# Modelos Python

A implementará aquí QPSK, generación de coeficientes, filtros flotantes y versiones de punto fijo según los [contratos](../docs/contratos/README.md). Cada modelo debe declarar formato, orden de muestras y latencia, y exportar vectores deterministas. Las pruebas van en `tests/`.

La utilidad [stimuli.py](stimuli.py), incorporada como evidencia de E01, separa la fuente QPSK con semilla (`generate_qpsk`) de la inserción de ceros (`upsample_2x`). El generador entrega símbolos I/Q = ±1 y puede reutilizarse en ambas ramas. La upsampling entrega exactamente dos muestras por símbolo, incluido el cero tras el último. Son operaciones Python sin latencia de reloj; el protocolo RTL se define en E03/C01. No se fija el mapeo bits → símbolos ni se da por completada A01. La [prueba de E01](../tests/test_frequency_overlap_contract.py) verifica el uso de estos estímulos con overlap-save y ocho taps; sus coeficientes de ejemplo no reemplazan la tabla de E02.

El modelo flotante [frequency.py](frequency.py) expone `frequency_filter(signal, taps)` para reutilizarlo en A03. Recibe una trama de muestras complejas y ocho coeficientes en orden causal; devuelve una salida por muestra, con historial inicial cero y sin cola final. Cada llamada procesa una trama independiente completa. Representa FFT16/IFFT16 mediante DFT directa, sin dependencias externas ni latencia de reloj. La convolución causal usada como referencia independiente permanece en el test.
