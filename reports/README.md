# Reportes

Aquí irán tablas finales pequeñas y conclusiones trazables a commit, configuración y logs. Las salidas pesadas de herramientas quedan en `build/` o en artefactos de CI; no se versionan como si fueran la fuente del resultado.

El [registro PPA en frecuencia](ppa/frequency.md) reúne las corridas y análisis de las variantes serial y optimizada, con sus medidas locales y resultados de Vivado.
