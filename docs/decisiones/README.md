# Decisiones de diseño

Guardar aquí una nota breve cuando una elección afecte a más de una persona o cambie la comparación PPA. Nombre sugerido: `001-filtro-frecuencia.md`. Cada nota debe contener fecha, problema, alternativas, decisión, motivo, efectos sobre modelo/RTL/pruebas y enlace a issue/PR. El estado y valor vigente también se reflejan en el [contrato técnico](../contrato-tecnico.md).
